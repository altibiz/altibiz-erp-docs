# Plan ugovaranja

### <p align=center>**Ažuriranje Plana ugovaranja**

**<p align=center>Put: Izvješća → Plan ugovaranja**

---

Svi projekti koji imaju status **Ponuđen** automatski ulaze u izvještaj Plan ugovaranja. Ovisno o procjeni vjerojatnosti ugovaranja, svim ponuđenim projektima je potrebno odrediti % u stupcu **Plan ugovaranja**.

Podaci o ponudama se unose odmah po saznanju informacija s tržišta, odnosno po objavi Zapisnika s otvaranja ponuda, dok se Odabrana ponuda označava odmah po primitku Odluke o odabiru. Točnije, potrebno je ažurirati plan ugovaranja (%) te pod napomenu upisati opisno status.

U izvještaju se gledaju projekti koji imaju:
- **Status** = Ponuđen
- **Stanje projekta** = Nuđenje

U lijevom dijelu prozora potrebno je odabrati **Sve godine**.
